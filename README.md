# Projeto Agrinho
O EcoAgro é uma aplicação web desenvolvida com HTML, CSS e JavaScript voltada para o pequeno e médio produtor rural. O objetivo principal da plataforma é unir a alta produtividade no campo à preservação ambiental, servindo como uma ferramenta de apoio para a tomada de decisões sustentáveis. Por meio de uma interface simples e intuitiva, o produtor pode calcular o uso ideal de recursos hídricos e insumos orgânicos, evitando o desperdício de água e a degradação do solo.

OBJETIVOS PRINCIPAIS DO PROJETO

.Otimização de Recursos: Ajudar o agricultor a calcular a quantidade ideal de água e fertilizantes com base no tamanho da sua propriedade e no tipo de cultura (grãos, hortaliças ou frutas).

.Conscientização Ambiental: Promover práticas ecológicas essenciais, como a rotação de culturas, a captação de água da chuva e a preservação de áreas nativas.

.Acessibilidade: Oferecer uma ferramenta gratuita, leve e de fácil entendimento, que pode ser acessada tanto pelo celular quanto pelo computador diretamente no campo.

TECNOLOGIAS UTILIZADAS

.HTML: Utilizado para a construção da estrutura da página, garantindo que o formulário de dados e as seções de dicas sejam organizados e acessíveis.

.CSS: Responsável pelo design visual da aplicação. Utiliza uma paleta de cores inspirada na natureza (tons de verde e terra), com um layout responsivo e limpo para facilitar a leitura.

.JavaScript: Responsável pela inteligência da página. O script processa os dados inseridos pelo usuário em tempo real, realiza os cálculos matemáticos de manejo e exibe o diagnóstico ecológico instantaneamente, sem necessidade de recarregar a página.

"O EcoAgro nasce para mostrar que o futuro do campo não precisa escolher entre produzir ou preservar; com a tecnologia certa, nós podemos fazer os dois."
